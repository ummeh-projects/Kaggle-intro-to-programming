# 🐍 Kaggle Intro to Programming Exercises

Welcome to my repository! This repository contains practice exercise notebooks completed as part of Kaggle's **Intro to Programming** course. It showcases foundational programming concepts, logic building, and problem-solving using Python.

---

## 📚 Covered Topics & Notebooks

Below is a summary of all the exercise notebooks included in this repository:

1. **Functions & Getting Help** (`exercise-functions (2).ipynb`)
   - Writing custom functions, setting default values, and understanding arguments.

2. **Conditions & Conditional Statements** (`exercise-conditions-and-conditional-statements (1).ipynb`)
   - Working with boolean logic, `if-elif-else` statements, and decision-making logic.

3. **Data Types** (`exercise-data-types.ipynb`)
   - Working with integers, floats, booleans, and strings in Python.

4. **Intro to Lists** (`exercise-intro-to-lists.ipynb`)
   - Creating, indexing, slicing, and modifying lists.

5. **Loops & List Comprehensions** (`exercise-loops-and-list-comprehensions.ipynb`)
   - Iterating over sequences using `for` and `while` loops, plus concise list comprehensions.

6. **Strings & Dictionaries** (`exercise-strings-and-dictionaries.ipynb`)
   - Key-value mappings, dictionary methods, and string manipulation.
